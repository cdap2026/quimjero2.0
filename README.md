# Examen de Química - Grado 6 (Con Imágenes Propias)
**Colegio Manantial de Dios**

Este repositorio contiene un examen interactivo en HTML5 que utiliza las imágenes personalizadas y adaptaciones metodológicas adecuadas para un estudiante con necesidades educativas especiales:
- **Hipoacusia bilateral y leve déficit cognitivo:** El examen es altamente gráfico, cuenta con 8 preguntas cerradas y 2 abiertas.
- **Sin restricciones de ventana/pestaña** para evitar distracciones o frustración por bloqueos del sistema.

## Archivos Incluidos
- `index.html`: Código fuente del examen.
- `image_0.png` a `image_8.png`: Imágenes de alta calidad y banner para el examen y el reporte.

## Publicación en GitHub Pages

1. Sube todos los archivos (`index.html`, `image_0.png`, `image_1.png`... `image_8.png`) a un repositorio en GitHub.
2. Asegúrate de que estén en la misma carpeta raíz.
3. En la configuración (**Settings**) del repositorio, ve a la sección **Pages**.
4. En **Source**, selecciona la rama `main` (o `master`) y guarda (**Save**).
5. ¡Listo! Se generará tu URL pública para que el estudiante realice el cuestionario de 45 minutos.

## Reporte PDF
El sistema lee de manera dinámica el banner y las imágenes, generando un reporte visual que el estudiante se descarga de forma local en formato `.pdf` apenas finaliza.
